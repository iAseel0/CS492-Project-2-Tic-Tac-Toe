
# CS492 - Project 2: Tic-Tac-Toe

## Project Description
A GUI-based Tic-Tac-Toe game developed using Python and Tkinter.

The game allows users to:
- Play against the computer or another player.
- Choose X or O.
- Choose who starts the game.
- Play on an interactive 3x3 board.

## Smart Computer Opponent
The computer uses the Minimax algorithm to select optimal moves. It tries to win, blocks the player's winning moves, and avoids losing.

## Technologies Used
- Python
- Tkinter
- Dictionary
- Minimax Algorithm

## How to Run
1. Install Python 3.
2. Download the project.
3. Run the following command:

```bash
python3 project2.py
```
